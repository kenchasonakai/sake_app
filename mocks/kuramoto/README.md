# 岩瀬酒造 蔵元カードゲーム

岩瀬酒造（岩の井）のハッカソン用に作った、1 人用カードゲームの盤面モックです。スマホの横画面で遊ぶ前提です。

公開版: https://claude.ai/artifact/GPdvRzUDuqJxagY4A4D626

## ファイル

| ファイル | 中身 |
| --- | --- |
| `kuramoto-phaser.html` | 盤面のモック。いまの版。HTML 1 枚で動く |
| `kuramoto-board.html` | 前の版。横画面の盤面を HTML と CSS だけで作ったもの |
| `kuramoto-mock.html` | 最初の版。縦画面で、場を上から順に並べたもの |
| `sim.py` | ルールの数字を確かめる簡易シミュレーター |

前の 2 つも遊べます。公開版は、横画面の HTML 版が https://claude.ai/artifact/H8yMmH9td8Kjt8rViYq4h8 、縦画面版が https://claude.ai/artifact/8BPn7TDGudL5cH6ogGFi2Z です。

## 開き方

`kuramoto-phaser.html` をブラウザで開きます。Phaser と Google Fonts を CDN から読むので、ネットに繋がっている必要があります。

7 ターン目の見本から始まります。「遊び方」から新しく始め直せます。

## 技術

- 描画と演出は Phaser 3.80.1。cdnjs から読みます。
- 盤面は 1280×720 で描き、カメラを 2 倍にして高解像度の画面でもにじまないようにしています。
- ルールは描画と分けた関数にしてあります。`Act` の各操作が状態を変え、`Board` のシーンが毎回盤面を描き直します。
- 遊び方と結果の画面だけ HTML で重ねています。

## モックで決めたルール

設計書で曖昧だったところは、モックでは次のように動かしています。

- 船頭は i240 山廃・山田錦には効かない。
- 出荷の効果は 1 つだけ持てる。持っている間に引いた効果は何も起きない。
- 出荷の効果は、そのターンにいちばん高く売れる酒に効く。
- 買った素材は手札に入る。使ったり捨てたりした後は捨て札に入らず、取引先に戻る。
- 置いた駒は次のターンもそのまま残る。
- 雇う、買う、仕込むはどの順でもよい。
- 最後の所持金で付く段の目安は S 170 両、A 140 両、B 110 両。仮の数字です。

## シミュレーター

```sh
python3 sim.py
```

雇い方の方針ごとに 2,000 回ずつ自動で遊び、20 ターン後の所持金と破産の割合を出します。方針は人より下手なので、数字の傾向を見るためのものです。

これまでに分かったこと:

- 誰も雇わないと平均 94 両。専門職と蔵人を雇うと 150 両前後まで伸びる。
- 能力を持つ人を 1 人足しても伸びない。今の効果は弱すぎる。
- 最初の出荷の前に雇うと、2〜4 ターン目に破産しやすい。
