# デザイン案の議論候補

UI を決める前に、決めておくと手戻りが減る論点。それぞれ「候補」と「寄せたい方向」を書く。最終判断は未定。

## 1. 言葉づかい（最重要）

主役は日本酒を知らない人。画面に出す語彙がそのまま製品の個性になる。

- 用語を出さない: 純米・吟醸・精米歩合・日本酒度は本文に出さない。出すなら折りたたみの「もっと詳しく」に。
- 味の軸の言い換え候補
  - 甘口〜辛口 → 「甘め ←→ すっきり辛め」
  - 淡麗〜濃醇 → 「軽やか ←→ コクあり」
  - 知名度 → 「定番 ←→ 知る人ぞ知る」
- 候補の説明文のテンプレ: 「どんな味か（1 文）」「どんな立ち位置か（定番 / 通好み）」「事実（ファンが多い、出回りが少ない、蔵が新しい）」「こんな人に」。各 1 文、合計 4 文以内。
- 決めること: 語彙のトーン（丁寧 / 友達口調）。LINE に貼る定型文と揃える必要がある。

## 2. 贈る流れの形

- 画面数: 3 画面（場面と予算 → 候補 → 一言とリンク）を上限にする。
- 任意のヒント（相手の好み、好きの度合い）の置き場所
  - 候補 A: 1 画面目の下に折りたたみ「分かれば」
  - 候補 B: 候補を見た後に「相手のこと、分かる？」で絞り直す
  - 寄せたい方向: A。「分からない」が既定であることが画面で伝わる。
- 候補の見せ方
  - 候補 A: 2〜3 枚のカードを縦に並べて比較
  - 候補 B: 1 枚ずつスワイプ
  - 寄せたい方向: A。「定番か、知る人ぞ知るか」の比較が主役の判断なので、並べて見える方がよい。
- 「決めた理由 → 一言の下書き」の作り方: 理由をチップで選ぶ（「定番で外さない」「ちょっと珍しい」「軽やかで飲みやすい」）→ 文に変換 → 編集可。自由入力から始めない。

## 3. 共有画面（LINE に貼る）

- 出すもの: リンク、定型文（コピー 1 タップ）、プレビューの見え方の説明。
- 定型文の候補: 「日本酒を一本送ったよ。このリンクから住所を入れると届くよ」程度の短さ。贈り主の一言はリンク先で読ませ、LINE 本文には入れない（OGP とプレビューに出る範囲を考える）。
- 決めること: 共有シート（OS 標準）に出すか、LINE だけに絞るか。

## 4. 受け取りページ（Web、JS なし）

- 並び順の候補: 贈り主の一言 → 一本の写真と説明 → 受け取る（成人確認と住所）→ 届いたあとにできること。
- 成人確認の形
  - 候補 A: 住所フォームの先頭のチェックボックス
  - 候補 B: ページを開いた瞬間の全画面確認
  - 寄せたい方向: A。離脱を増やさない。店側の要件が出たら B に変える。
- 届くまでの画面（住所送信後に同じリンクを開いた時）: 配送状況を主に、アプリの案内は下に小さく。
- 決めること: 贈り主の本名を出すか、呼び名だけか（LINE のグループで開かれる可能性）。

## 5. 記録（アプリ）

- 入力は 3 タップで終える: 「また飲みたい / ふつう / 合わなかった」＋ 任意の一言。評価の星や 10 点は使わない。
- 「開けたよ」が贈り主に届くことを、記録ボタンの直前に 1 行で予告する（「贈り主に『開けたよ』が届きます。感想は届きません」）。
- 記録一覧は「もらった / 贈った / 自分で飲んだ」をタブではなく、1 本のタイムラインにマークで区別する案。

## 6. 見た目

- 方向の候補
  - 和の素材感（生成り、墨、藍の差し色）
  - 今風のギフト EC（白地、写真が主役、丸いボタン）
  - 寄せたい方向: 後者を基調に、差し色で和を少し。「日本酒を知らない人」が身構えない方が優先。
- 書体: Noto Sans JP（無難）か Zen Kaku Gothic New（やわらかい）。本文は 16px 以上。
- 画像: 瓶の実写はラベルの権利と撮影の手間がある。最初はイラスト（統一感）か、店から提供される商品写真。候補の説明が主役なので画像なしでも成立する設計にしておく。
- ダークモード: Expo のテンプレどおり対応する。受け取りページも `color-scheme` で追従。

## 7. 名前とトーン

- アプリ名は未定（仮に Sake）。LINE の定型文、OGP、ストア名で同じ名前を使うので早めに決める。
- 候補の出し方: 「贈る」「一本」「外さない」のどれを核にするか。

## 8. 決めていないこと（議論待ち）

1. 言葉のトーン（丁寧 / 友達口調）
2. 候補の提示数（2 本か 3 本か）
3. 贈り主の表示（本名 / 呼び名）
4. 見た目の方向（和 / 今風）
5. 画像の用意（イラスト / 店の写真 / なし）
6. アプリ名
