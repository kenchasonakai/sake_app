# 画面設計

前提: [decisions.md](decisions.md) の D19〜D22、[flows.md](flows.md)。図は配置のたたき台で、寸法や細かな文言は実装時に詰める。

## 共通の決まり

- **言葉**: すべて丁寧語（D19）。用語（純米、吟醸、精米歩合、日本酒度）は本文に出さず、「もっと詳しく」を開いた時だけ。
- **見た目**: ギフト EC を基調に、差し色に藍を少しだけ使う（D22）。下の表を使う。
- **20 歳未満の飲酒禁止の表示**: 候補、確認、受け取りページの下に小さく置く（D16）。
- **デモの注記**: 確認画面と受け取りページに置く（D14）。

### 色と形

| 用途 | ライト | ダーク |
| --- | --- | --- |
| 背景 | #FFFFFF | #121212 |
| 面（カード、入力欄） | #F5F5F3 | #1E1E1E |
| 文字 | #1F1F1F（墨） | #ECECEC |
| 補助の文字 | #6B6B6B | #A0A0A0 |
| 差し色（主ボタン、選択中、おすすめの印） | #264A7A（藍） | #8FB0DE |
| 線 | #E4E4E0 | #2E2E2E |

- 角丸はカード 16、入力欄 12。ボタンは丸い形（全幅で高さ 52 前後）。
- 書体は Zen Kaku Gothic New。本文 16、見出し 22〜24、補助 13。アプリは `@expo-google-fonts/zen-kaku-gothic-new`（Expo Go で使える）、Web は Google Fonts。
- おすすめの印は 2 種類を形で区別する。定番は藍の塗り、定番以外は藍の線。

### 味と立ち位置の見せ方

3 本の軸を、両端に言葉を置いた 5 段の点で見せる。数字は出さない。

```
甘め        ●●○○○  すっきり辛め
軽やか      ●●●○○  コクあり
定番        ●○○○○  知る人ぞ知る
```

## アプリ（Expo Go）

タブは「ホーム」「記録」「設定」の 3 つ。贈る流れはタブの上に重ねて開く。

│ ┌───────────────────────────┐ │

開いた時の「お相手について」:

```

│ ( 甘め ) ( すっきり ) ( 分からない ✓ ) │

- 予算は自由入力ではなく区切りから選ぶ。区切りの値は未定で、カタログに入れる容量で決まる（[research/prices.md](research/prices.md)）。図の値は仮。
- 好みの既定は「分からない」。

### A3. 候補（G3）

1 枚ずつ左右にめくる（D21）。予算内の候補をすべて出し、先頭の 2 枚におすすめの印を付ける（D20）。

```
┌───────────────────────────────┐
│ ‹  誕生日 ・ 3,000円まで   変更 │
│                     1 / 12    │
│  ┌─────────────────────────┐  │
│  │ ■ おすすめ・定番          │  │ ← 藍の塗り
│  │ 誕生日に贈るなら、         │  │
│  │ まずはこの一本です。       │  │
│  │                         │  │
│  │      [ 瓶の絵 ]          │  │
│  │                         │  │
│  │ ○○ 純米          300ml   │  │
│  │ ○○酒造（新潟）    1,650円 │  │
│  │                         │  │
│  │ 甘め    ●●○○○ すっきり辛め │  │
│  │ 軽やか  ●●●○○ コクあり    │  │
│  │ 定番    ●○○○○ 知る人ぞ知る │  │
│  │                         │  │
│  │ (ファンが多い)(賞を取った)  │  │
│  │ 説明 4 文以内              │  │
│  │ ▸ もっと詳しく             │  │
│  └─────────────────────────┘  │
│  [ この一本にする ]             │
│  20歳未満の者の飲酒は法律で禁止されています │
└───────────────────────────────┘
```

2 枚目は「□ おすすめ・定番以外」（藍の線）で、「誕生日に少し特別感を出すなら、この一本です。」のような一文が付く。3 枚目以降は印なし。

- 並び: 定番のおすすめ、定番以外のおすすめ、残りをスコア順。
- 「1 / 12」で全体の数を見せる。左上の「‹」でおすすめの 1 枚目に戻れる。
- めくりは横向きの FlatList のページ送りで作る。Expo Go で動く範囲に収める。
- 予算内の候補が 1 本もない時は「このご予算では候補が見つかりませんでした」と予算の変更を促す。

### A9. 記録の一覧（記録タブ）

```
┌───────────────────────────────┐
│ 記録                    [ ＋ ]  │
│ ┌───────────────────────────┐ │
│ │ 🎁 ○○ 純米     10/16        │ │ ← もらった一本
│ │    また飲みたい              │ │
│ └───────────────────────────┘ │
│ ┌───────────────────────────┐ │
│ │    □□ 吟醸     10/02        │ │ ← 自分で飲んだ
│ │    ふつう                    │ │

│                               │

- もらった一本と自分で飲んだ酒を 1 本の時系列に並べ、印で区別する。

## 運営画面（O4、たたき台）

Web の Worker の `/admin` に置き、Cloudflare Access で守る案。

- **M1. 手配の一覧**: 状態（手配待ち、手配済み、発送済み、届いた）で絞り込む。1 行に受け取った日時、一本、状態。
- **M2. 手配の詳細**: 届け先、一本、一言。状態を 1 つ進めるボタンが 1 つだけある。
- **M3. カタログ**: 一覧と編集。味の 3 軸、事実のタグ、説明、価格、公開と非公開。
